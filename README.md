# Kapan Nieh? 🚀
> Penyelamat Jadwal Gabutmu

Web aplikasi berbasis *room* sementara untuk menghitung dan menampilkan irisan waktu luang bersama seluruh anggota kelompok atau tim secara otomatis, instan, dan aesthetic.

## ✨ Fitur Unggulan
- **Tanpa Login Ribet**: Cukup masukkan nama dan pilih chibi pixel avatar favoritmu.
- **Visualisasi Heatmap**: Warna hijau untuk waktu kosong bersama (sempurna), kuning/merah untuk jam sibuk atau bentrok jadwal kuliah/kerja.
- **Auto Expiry**: Room otomatis terhapus dalam waktu 24-48 jam agar server tidak penuh dengan data sampah.
- **Export & Share**: Simpan hasil jadwal ke format PNG/PDF atau bagikan langsung via link.
- **Custom Theme & Mode**: Mendukung mode Gelap (Dark), Terang (Light), dengan sentuhan warna utama `#10377D`.
- **Bilingual Support**: Tersedia bahasa Indonesia dan English.
- **Chibi Pixel Avatars**: Pilihan avatar kucing, anjing, panda, kelinci, burung hantu, rubah, dll.
- **Responsive**: Nyaman digunakan di Laptop maupun Smartphone.

---

## 🛠️ Cara Menjalankan & Upload ke GitHub

1. **Clone atau Download repository ini.**
2. **Jalankan secara lokal**: Buka file `index.html` langsung di browser manapun (Chrome, Safari, Firefox, Edge).
3. **Deploy ke GitHub Pages**:
   - Buat repository baru di GitHub (misal: `kapan-nieh`).
   - Upload file `index.html` dan `README.md` ke repository tersebut.
   - Masuk ke **Settings > Pages**, lalu set source ke branch `main` / `root`.
   - Web aplikasimu siap dibagikan ke teman-teman kelompokmu!
